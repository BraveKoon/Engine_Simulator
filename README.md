# 엔진 시뮬레이터

브라우저에서 돌아가는 3D 엔진 시뮬레이터입니다. 엔진을 고르고 시동을 건 뒤, 액셀·브레이크 페달과 H 패턴 변속기로 직접 운전해 볼 수 있습니다.

## 기능

- **시작 화면**: 엔진 시뮬레이터 / 차량 만들기 중 선택
- **차량 만들기**: 엔진 → 차체(모노코크·프레임바디) → 휠 크기(15~22인치)를 고르면 조건에 맞는 차가 3D로 생성됩니다
  - 휠 크기마다 휠 이미지(타이어 규격 포함)와 그 크기를 쓰는 대표 차종 표시
  - 해치백·세단·쿠페·슈퍼카·SUV·오프로더·픽업트럭 중 조합에 맞는 차체, 색상 변경
  - 조건에 맞는 실제 양산차(약 50종 데이터)를 찾아 그 차의 치수·차체 형태·무게로 모델을 만들고, 해당하는 차가 없는 차체·휠 크기는 흐리게 비활성화
  - 실제 3D 모델이 있는 차 43종(모델 파일 40개)은 실제 모델로 표시하고 바퀴가 굴러가요 — 출처는 [CREDITS.md](CREDITS.md)
  - 시뮬레이터로 0→100 km/h, 최고속도를 추정하고, 그 차의 무게·타이어·공기저항으로 바로 운전 가능
- **엔진 선택 화면**: I4 · I6 · V6 · V8 · V10 · V12 · W16 · 수평대향 6기통(박서)
- **3D 엔진 뷰** (Three.js)
  - 드래그로 회전, 핀치/휠로 확대·축소, 두 손가락/우클릭으로 이동
  - 시점 프리셋(사선 · 정면 · 측면 · 위 · 뒤), 전체 화면, 슬로모션
  - 크랭크축 · 피스톤 · 커넥팅 로드 · 캠축 · 밸브 · 타이밍 벨트 · 배기 매니폴드 · 터보가 실제 회전수에 맞춰 움직이고, 점화 순간 연소실이 빛납니다
  - 타이밍 벨트가 크랭크 스프로킷(16T) → 캠 스프로킷(32T, 2:1)을 실제 속도로 돌고, 캠 사이 기어가 흡기 캠을 반대 방향으로 돌립니다
  - 투명 6단 변속기: 인풋 · 카운터 · 아웃풋 샤프트 기어가 맞물려 돌고, 선택한 기어와 싱크로 슬리브가 주황색으로 표시되며 시프트 레버가 H 패턴대로 움직입니다
  - 각 엔진의 뱅크각, 크랭크 핀 배치, 점화 순서를 실제처럼 계산 (균등 점화)
- **계기판**: 타코미터(레드존, 시프트 라이트), 속도(km/h · mph), 현재 기어, 엔진 상태
- **조작**
  - 시동/정지 버튼 (스타터 크랭킹 → 공회전)
  - 브레이크 · 액셀 페달 (누르는 위치가 높을수록 깊게 밟힘)
  - H 패턴 6단 수동 변속기 (노브를 끌거나 기어 번호를 탭) — 클러치는 자동
- **물리**: 토크 곡선, 터보 부스트 지연, 레브 리미터, 엔진 브레이크, 반클러치 출발, 공기저항·구름저항, 엔진 꺼짐(스톨)
- **사운드**: AudioWorklet 기반 절차적 엔진음 (실린더별 점화 펄스 + 배기 공명), 터보 휘슬, 블로오프 밸브, 스타터 모터

### 키보드

| 키 | 동작 |
| --- | --- |
| `↑` / `W` | 액셀 |
| `↓` / `S` / `Space` | 브레이크 |
| `1`–`6`, `R`, `N` | 기어 선택 |
| `X` / `Z` | 업 / 다운 시프트 |
| `E` | 시동 켜기/끄기 |

## 실행

```bash
npm install
npm run dev      # 개발 서버 (같은 Wi-Fi의 휴대폰에서도 접속 가능)
npm run build    # dist/ 에 정적 파일 생성
npm run preview
```

`v*` 태그를 푸시하면 `.github/workflows/release.yml` 이 GitHub 릴리스를 만들고, 한 파일짜리 `engine-simulator.html` 과 빌드 zip 을 첨부합니다
(`npm run build && npm run standalone` 으로 로컬에서도 만들 수 있습니다).

`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml` 이 GitHub Pages 로 배포합니다
(저장소 Settings → Pages → Source 를 **GitHub Actions** 로 설정).

## 구조

```
src/
  engines.js    엔진 사양, 실린더 배치, 점화 순서, 토크 곡선
  physics.js    엔진 · 자동 클러치 · 변속기 · 차량 시뮬레이션
  engine3d.js   절차적 3D 엔진 모델과 카메라/조작
  audio.js      AudioWorklet 엔진 사운드
  ui/gauge.js   타코미터
  ui/controls.js 페달, H 패턴 변속기
  main.js       화면 전환과 메인 루프
```

## 차량 3D 모델 추가

1. Sketchfab 등에서 CC 라이선스 모델(.glb 또는 glTF zip)을 받아 한 폴더에 둡니다.
2. `tools/models.json`에 항목을 추가합니다 (`src` 원본 경로, `out` 파일 이름, `cars` 차 이름, 필요하면 `paint`·`yaw`·`drop`·`up`·`colors`).
3. `node tools/build-models.mjs <원본 폴더> <out 이름>` — 방향·크기 맞춤, 바퀴 분리, 압축 후 `public/models/`와 `src/car/models.json`, `CREDITS.md`가 갱신돼요.
4. `tools/model-check.html`(개발 서버에서 열기)로 방향과 바퀴(분홍색)를 확인합니다.
